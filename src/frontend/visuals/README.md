# src/frontend/visuals — Recursos visuales

Estáticos de la UI, separados por tipo: `assets/`, `icons/`, `images/`, `templates/`, `themes/`.

- `assets/` — fuentes y ficheros estáticos no-imagen.
- `icons/` — iconos.
- `images/` — imágenes (aquí van las institucionales: logos, banners).
- `templates/` — plantillas de render/documento (LaTeX, Jinja→LaTeX/HTML, reportes, correo).
- `themes/` — temas visuales.
